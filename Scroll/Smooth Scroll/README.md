# Smooth Scroll

A sleek, inertia-based smooth scrolling component built for modern React and Next.js applications. Designed to deliver buttery-smooth vertical scrolling experiences with minimal setup and clean customization.

🔗 **[Live Preview & Component Source](https://21st.dev/@uilayout.contact/components/smooth-scroll)**

---

## ✨ Features

- **Buttery Smooth Inertia:** Eliminates harsh native scroll jumps with customizable damping and easing.
- **Lightweight & Performant:** Built on modern animation primitives (such as Lenis / Motion) for 60fps+ rendering.
- **Drop-in Wrapper:** Easily wrap your entire application layout or individual scroll containers.
- **Responsive & Touch-Friendly:** Automatically adapts to desktop trackpads, mouse wheels, and mobile touch gestures.

---
